# Emoji Impact

Code repository link: https://github.com/daxus4/emoji_impact

The version used in the paper is 515efc7

## Project description
This project investigates the impact of emojis and sentiment-bearing words on financial sentiment classification in social media. Using over 1.4 million StockTwits messages and a RoBERTa-based model, controlled ablation experiments are conducted to measure the contribution of each component to bullish/bearish classification. Results show that sentiment-bearing words provide the strongest predictive signal, while emojis contribute additional information, highlighting the importance of preprocessing choices in financial NLP applications.
